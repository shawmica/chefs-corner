🚀 Project Launch | Chef’s Corner 🍳🍽️

I’m excited to officially share Chef’s Corner, a Full-Stack Recipe Management Web Application that I designed and built from scratch as part of my web development journey.

🔥 About Chef’s Corner
Chef’s Corner is a recipe management platform where users can:
🍽️ Browse various recipes with detailed views
🔍 Search & Filter recipes by title or tags in real-time
👨‍🍳 Admin Panel to Add, Edit, and Delete Recipes

💻 Tech Stack:
Frontend:
✅ React + TypeScript + Shadcn UI for modern UI
✅ React Router for navigation
✅ Axios for API communication

Backend:
✅ Django & Django REST Framework for REST APIs
✅ JWT Authentication for secure admin control
✅ Django Admin Panel for recipe management

🌟 Features Implemented:
🔄 Dynamic API-Powered Interface

🔍 Real-Time Recipe Search & Filter

🛠️ Admin CRUD Management Panel

📑 Detailed Recipe View with Ingredients & Instructions
